# Diagram sources

Hand-laid-out SVGs in `docs/assets/` are generated by `generate_svgs.py`:

```console
python docs/assets/src/generate_svgs.py
```

Edit the script rather than the generated SVGs, then regenerate and commit both.
Flow-style diagrams live as Mermaid blocks directly in
[`docs/visual-guide.md`](../../visual-guide.md) and need no build step.

Shared colour semantics across all diagrams:

| Colour | Meaning |
|---|---|
| Green | Measured source evidence |
| Amber | Estimated values (reconstruction, pose estimation, clock mapping) |
| Blue | Exact derivations (frame transforms, resampling, action construction) |
| Purple | Retargeted or simulated values |
| Grey | Packaging and delivery |

Generated SVGs use a white background so they stay legible in both light and
dark GitHub themes.
